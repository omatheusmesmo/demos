# Benchmark 2026-10-21, Quarkus 4.0.0.Beta1

Machine: AMD Ryzen 5 5600GT with Radeon Graphics, 12 logical CPUs, Linux 7.2.5-3-omarchy.
Application: CPUs 2,3 (-XX:ActiveProcessorCount to match), 1g memory, heap 512m (Xms = Xmx), -XX:+UseParallelGC.
Load generator: Hyperfoil 0.29.3 on CPUs 4,5,10,11, open model (constant arrival rate), 10 s request timeout. Dependencies on CPUs 0,1,6,7.
Each variant: 3 iterations, each a fresh JVM with a 2m warmup and a 30 s cooldown, then every rate for 30s in ascending order, 15 s apart.

Values are the median across iterations, with the range in parentheses when they differ. Achieved counts
2xx responses per second. Errors are started requests that did not end in a 2xx (timeouts included).
Unsent are scheduled requests the load generator could not start because every session was busy. CPU is the
mean of the application container (200% is both CPUs), RSS the peak resident set of the JVM, GC the pause
time inside the measured window. Other CPU is time other host processes took on the application CPUs.
